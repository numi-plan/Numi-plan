🛰️ Installation de la Synchronisation GPS (IdeGPS / Geoloc.dz)

Ce bookmarklet vous permet de synchroniser les positions GPS réelles de vos véhicules directement depuis le site IdeGPS ou Geoloc.dz vers votre outil Numiplan.

🛠️ Comment l'installer en 3 secondes :

  1. Assurez-vous que votre barre de favoris est visible dans votre navigateur (sur Chrome: Ctrl + Maj + B).
  2. Glissez et déposez le bouton bleu ci-dessous directement dans votre barre de favoris.
  3. Si vous préférez l'ajouter manuellement : créez un favori, nommez-le 🛰️ Synchro GPS et collez le code du bloc ci-dessous dans le champ Adresse/URL.
👈 Glisser ce bouton dans vos favoris

📋 Code de secours (Copier/Coller manuel) :

Si le glisser-déposer ne fonctionne pas sur votre navigateur, vous pouvez copier le code ci-dessous et l'insérer comme adresse (URL) d'un favori existant :

Numiplan — Module d'automatisation des pointages GPS — Version 2026.07
